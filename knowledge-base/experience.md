# Professional Experience

## Wheels&Trade — Full-Stack Engineer Intern
**Role:** Solo Full-Stack Developer (end-to-end)
**Type:** Internship
**Stack:** React, TypeScript, React Native, FastAPI, PostgreSQL

### Context
Wheels&Trade is a logistics company. Riad was the sole developer on this project — from specifications to MVP delivery. There was no team, no senior engineer to lean on. He owned the entire product lifecycle.

### What He Built
A complete internal management platform covering:

**Web Platform:**
- **User management** — multi-role system covering drivers, back-office staff, and clients, each with their own permissions and views
- **Transportation management** — creating new deliveries, fetching historical delivery records, and real-time delivery tracking
- Full CRUD operations, role-based access control, and a clean back-office interface

**Mobile App (React Native MVP):**
- Built for drivers in the field
- Drivers could update delivery statuses in real time
- Drivers could fetch their planning — daily, weekly, or monthly delivery schedules
- Synced with the web platform backend

### Key Achievement
Riad took this project from a blank page to a working MVP entirely by himself — writing the specifications, designing the architecture, building both the web and mobile apps, and delivering a functional product. This is the most defining proof of his end-to-end capability.

## INOVTEAM — Full-Stack Engineer Intern
**Role:** Full-Stack Developer in an Agile Team
**Type:** Internship
**Stack:** React, TypeScript, React Native, MariaDB (backend stack managed by team)

### Context
INOVTEAM is a product company. Riad worked within a structured agile team, contributing to an existing platform rather than building from scratch. This experience is complementary to Wheels&Trade — it demonstrates he can operate in both solo and team environments.

### What The Platform Does
A merchandising management platform with:
- **Multi-role user management** — Super Admin, Back Office, Manager, Merchandiser — each with distinct access and workflows
- **Planning management** — scheduling merchandisers across locations and assignments
- **Location management** — tracking where merchandisers operate
- **Data management** — collecting and organizing data submitted by merchandisers in the field
- **Mobile app** — a React Native application for merchandisers to execute their tasks on-site

### Riad's Contributions
1. **Frontend-Backend integration** — the platform was operating statically (hardcoded/mock data). Riad's primary responsibility was making it fully dynamic by connecting the frontend to real backend APIs.
2. **Mobile app support** — assisted a colleague who was responsible for the React Native mobile app, contributing to its development and integration.

### Key Achievement
Demonstrated strong integration skills and the ability to ramp up on an existing codebase in a team context — a different and equally important skill set from solo development.
